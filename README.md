# Gravity Assist

A small space game about flying a one-engine rocket through gravity wells. Grab every beacon, reach the gate, don't run out of fuel.

**Play:** https://savvystuffs.github.io/GravityAssist/

20 levels. Keyboard: arrows (or WASD) to fly, R to restart, P to pause, G for the orbit guide. On a phone, use the on-screen buttons.
